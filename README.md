# AI/ML Task: Relationship Analysis

## Objective
To analyze the relationship between two numerical variables using scatter plots and correlation analysis.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Dataset
A sample dataset containing Study_Hours and Marks.

## Methodology
1. Create a sample dataset using Pandas.
2. Calculate the correlation coefficient.
3. Visualize the relationship using a scatter plot.
4. Identify the direction and pattern of the relationship.
5. Record observations and conclusions.

## Observations
- Study hours and marks show a generally positive relationship in the sample.
- The scatter plot makes the pattern between variables easier to understand.
- Correlation measures the direction and strength of a linear relationship.
- Correlation alone does not prove causation.

## Conclusion
Relationship analysis helps identify associations and patterns between numerical variables. Scatter plots and correlation coefficients are useful tools for exploratory data analysis and machine learning.

## How to Run
Install the required libraries using `pip install pandas matplotlib`, then run the Python code in Jupyter Notebook.
